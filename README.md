# film-crew-media

Public staging for images the *Yard Work* crew passes into Kaitoi as model inputs. Public on purpose: Kaitoi imports a file by URL, and this is a URL it can reach.

Only what may go into a model lives here: our own renders, sheets, stills and storyboards. Never film frames or reference photos (rules in the private `film-crew` repo, CLAUDE.md, "Images"). The private repo is the record; this is a mirror for the machine.

Pushed by `scripts/media_push.py` in `film-crew`. Raw links look like:
`https://raw.githubusercontent.com/kaibarry/film-crew-media/main/<film>/<path>`
